# Family Guard — MVP

Проект состоит из Android-приложения ребёнка и плагина для WordPress. Он предназначен только для открытого родительского контроля собственного семейного устройства.

## Возможности версии 0.1

- подключение телефона к сайту одноразовым шестизначным кодом;
- передача геолокации, заряда и статистики приложений за последние 24 часа;
- отображение времени использования WhatsApp (`com.whatsapp`) без доступа к сообщениям;
- удалённое обновление списка заблокированных приложений;
- запрос снимка с фронтальной камеры через заметное уведомление;
- снимок создаётся и отправляется только после нажатия кнопки на телефоне ребёнка;
- постоянное системное уведомление во время мониторинга;
- токен каждого устройства хранится на сервере только в виде SHA-256-хеша.

Проект не читает сообщения WhatsApp, не записывает звук, не скрывает значок, не включает камеру тайно и не обходит системные разрешения Android.

## Установка WordPress-плагина

1. Сделайте резервную копию WordPress.
2. Убедитесь, что сайт работает через HTTPS.
3. Упакуйте папку `wordpress/family-guard` в ZIP или используйте готовый `family-guard-wordpress.zip`.
4. В WordPress откройте «Плагины → Добавить плагин → Загрузить плагин».
5. Активируйте **Family Guard** и откройте одноимённый раздел слева.
6. Нажмите «Создать новый код». Код действует 10 минут и только для одного телефона.

## Подключение телефона

1. Соберите и установите APK из папки `android`.
2. Введите HTTPS-адрес сайта, одноразовый код и имя телефона.
3. Последовательно разрешите геолокацию, уведомления и доступ к статистике приложений.
4. Для блокировки приложений вручную включите службу специальных возможностей Family Guard.
5. Нажмите «Запустить защиту».

## Блокировка WhatsApp

В панели устройства введите `com.whatsapp` в поле заблокированных пакетов. Несколько пакетов разделяются запятыми. Пустой список снимает ограничения.

## Версии Android-приложения

- `lite` (`assembleLiteRelease`): без службы специальных возможностей и без блокировки приложений.
- `full` (`assembleFullRelease`): с блокировкой приложений. Код и манифест службы лежат в `android/app/src/full`.

## Требования для сборки Android

- Android Studio с JDK 17;
- Android SDK 35;
- интернет при первой сборке зависимостей;
- команда сборки: `gradle assembleDebug` или кнопка Run/Build в Android Studio.

Debug APK после успешной сборки находится в `android/app/build/outputs/apk/debug/app-debug.apk`. Для постоянной установки необходимо создать собственный release keystore и подписать release-сборку.

## Важные ограничения

- На Android фоновые функции зависят от разрешений, настроек экономии батареи и производителя телефона.
- Google Play требует маркировку приложения как `child_monitoring`, постоянное уведомление и прозрачное описание мониторинга. Флаг уже добавлен в манифест.
- Служба специальных возможностей используется только для закрытия пакетов из списка ограничений. Публикация в Google Play потребует отдельного обоснования её использования.
- Перед использованием проверьте требования законодательства вашей страны и объясните ребёнку, какие данные видит родитель.
