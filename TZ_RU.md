# Техническое задание — Family Guard 1.0

Профессиональная система родительского контроля и поиска телефона уровня Prey / Life360 / Google Family Link: мобильное приложение (APK) + плагин WordPress с единой панелью управления.

Документ описывает **что должно получиться**, **как это выглядит** и **как работает**. Это основа для переделки текущего MVP (0.4.0) в полноценный продукт 1.0.

**Принцип честности (не передоговаривается):** система работает открыто. Никакой скрытой съёмки, прослушки и чтения переписки. Ребёнок всегда видит, что защита включена. Это требование закона и правил Google и условие того, что приложение вообще устанавливается.

---

## 1. Общая идея

Family Guard — связка «телефон ребёнка ↔ сайт родителя»:

- На телефоне ребёнка стоит приложение, которое с согласия передаёт на сайт родителя геолокацию, статистику приложений, заряд и состояние защиты.
- Родитель заходит в свою панель WordPress и видит все телефоны семьи на карте, историю, статистику и кнопки действий.
- Связь устанавливается один раз по QR-коду или одноразовому коду.

Ориентир по качеству — **Prey Anti-Theft** и **Life360**: чистый интерфейс, понятные статусы, карта на главном, крупные кнопки.

### 1.2. Чего система НЕ делает (сознательно, не обсуждается)

- **Нет скрытой съёмки** — фото/видео только после того, как ребёнок сам нажал кнопку (C1). Единственное исключение — A5 (антивор после неудачных попыток PIN), и то открыто, с предупреждением на устройстве. Снимок «при каждой разблокировке / при входе в приложение / по таймеру» не делается — это слежка за человеком, она незаконна, и Google блокирует такие приложения.
- **Нет прослушки микрофона и чтения переписки/сообщений.**
- **Нет маскировки** — иконка не прячется, приложение не притворяется другим.

Эти ограничения — часть продукта. Они делают его легальным и устанавливаемым.

## 2. Архитектура

```
┌─────────────────┐        HTTPS (REST API)        ┌──────────────────────┐
│  APK (ребёнок)  │  ───────────────────────────▶  │  WordPress + плагин   │
│                 │   pair / telemetry / snapshot   │  (сайт родителя)      │
│  фоновый сервис │  ◀───────────────────────────  │                       │
│                 │        команды (poll)           │  БД: устройства,      │
└─────────────────┘                                 │  телеметрия, события  │
                                                     └──────────┬───────────┘
                                                      Панель (одна страница)
```

- **Транспорт:** только HTTPS. Токен устройства в заголовке `Authorization: Bearer <token>`, не в URL.
- **Связь:** телефон раз в N минут (5–120, настраивается) шлёт телеметрию и забирает очередь команд (polling). Отдельный push-канал в 1.0 не требуется — работает на обычном хостинге WordPress.
- **Хранение:** БД WordPress (таблицы `fg_*`). Снимки — в закрытой папке, отдаются только администратору.

### 2.1. REST API (`/wp-json/family-guard/v1/`)

| Метод | Путь | Назначение | Авторизация |
|---|---|---|---|
| POST | `/pair` | привязать телефон по одноразовому коду, выдать токен | одноразовый код |
| POST | `/telemetry` | принять пакет (гео, приложения, заряд, события) | токен устройства |
| GET | `/commands` | забрать очередь команд | токен устройства |
| POST | `/snapshot` | загрузить снимок (C1 / A5) | токен устройства |
| POST | `/event` | разовое событие (SOS, геозона, смена приложения) | токен устройства |
| POST | `/ack` | подтвердить выполнение команды | токен устройства |

### 2.2. Таблицы БД

- `fg_devices` — телефоны: id, имя, профиль ребёнка, токен, версия, дата привязки.
- `fg_telemetry` — отчёты: гео, заряд, экранное время (итог + JSON по приложениям), набор разрешений, время.
- `fg_events` — события: тип (sos / geofence_enter / geofence_exit / new_app / low_battery / limit / power_off), данные, время.
- `fg_geofences` — геозоны: имя, координаты, радиус, на какой телефон.
- `fg_commands` — очередь команд: тип, параметры, статус.
- `fg_snapshots` — снимки: файл (в закрытой папке), источник (consent / anti-theft), время.

## 4. Мобильное приложение (APK)

### 4.1. Карта экранов
```
Splash → (не привязан) → Онбординг → Привязка (QR / код) → Разрешения → Главный
                                                                            │
                     ┌──────────────┬──────────────┬──────────────┬────────┴───────┐
                  Настройки    Экранное время   Режим пропажи   SOS / контакты   Запрос снимка
```

### 4.2. Splash
Логотип-щит на градиенте, 0.8 сек → если привязан, на Главный, иначе на Онбординг.

### 4.3. Онбординг (3 слайда)
1. «Family Guard помогает родителям знать, что ребёнок в безопасности.»
2. «Геолокация, экранное время, поиск телефона — всё честно и открыто.»
3. «Ребёнок всегда видит, что защита включена.» → «Начать».

### 4.4. Привязка
Вкладки **Сканировать QR** (по умолчанию) и **Ввести код**. QR: превью камеры с видоискателем, после распознавания поля заполняются сами. Вручную: адрес сайта (`https://…`), код, имя телефона. «Подключить» → `/pair` → Разрешения. Ошибки — понятным текстом.

### 4.5. Разрешения
Карточки с иконкой, пояснением и статусом. **Каждое объясняется pop-up окном, а не молчаливым переходом в настройки:**
1. Геолокация («Разрешить всегда») — показывать на карте.
2. Уведомления — показывать, что защита работает.
3. Доступ к статистике приложений — считать экранное время.
4. Отключить экономию батареи — не выключать защиту в фоне.
5. Только full: служба спец. возможностей — лимиты и блокировка приложений.

«Готово» активно при выданных обязательных (гео + уведомления); остальное можно догрузить, Главный подсветит нехватку.

### 4.6. Главный экран (как Prey)
- **Шапка** (градиент): имя телефона, крупный статус «Защита активна» (зелёная точка) / «Приостановлена».
- **Карточка состояния:** заряд, последняя синхронизация, экранное время сегодня / лимит.
- **Карточка «Разрешения»:** жёлтая с кнопкой «Исправить», если чего-то нет.
- Большая кнопка **«Запустить защиту» / «Остановить»**.
- Навигация внизу: Главная, Экранное время, Настройки.
- Постоянное уведомление в шторке «Family Guard защищает этот телефон».

### 4.7. Экранное время (экран)
- Кольцо/полоса: всего сегодня vs лимит.
- Список приложений с временем (YouTube, игры…), по убыванию.
- Переключатель День / Неделя.

### 4.8. SOS и контакты
Крупная красная кнопка SOS (шлёт событие + геолокацию родителю), список экстренных контактов для быстрого звонка.

### 4.9. Запрос снимка (C1)
Заметное уведомление → экран с превью камеры, текст «Родитель просит сделать снимок», кнопки «Сделать и отправить» / «Отклонить». Без автосъёмки.

### 4.10. Режим пропажи (A1)
Полноэкранный красный экран поверх блокировки: сообщение родителя, кнопка «Позвонить владельцу», громкий сигнал (STREAM_ALARM). Выключается только по PIN. Гео обновляется чаще.

### 4.11. Настройки
Интервал передачи (5–120 мин); дневной лимит; лимиты на приложения; PIN родителя (SHA-256); защита от удаления (переключатель, требует PIN, честное предупреждение); экран владельца (имя + запасной номер); тема; язык; «Отвязать» (по PIN); версия и адрес сайта.

## 5. Плагин WordPress

### 5.1. Пункт меню — одна иконка
В боковом меню админки — **один верхнеуровневый пункт с иконкой-щитом**; по клику открывается отдельная полноценная страница со всеми данными и настройками. Навигация — вкладками внутри страницы, подпунктов в меню нет.

```php
add_menu_page(
  'Family Guard', 'Family Guard', 'manage_options',
  'family-guard', 'fg_render_app',
  'data:image/svg+xml;base64,...щит...', 58
);
```

### 5.2. Страница-приложение (вкладки)
Оформлена по дизайн-системе (шапка-градиент, карточки):

1. **Обзор** — карта всей семьи (F1), карточки телефонов (онлайн/офлайн, заряд, синхронизация, экранное время сегодня), блок предупреждений (нет связи, снято разрешение, низкий заряд, превышен лимит, SOS).
2. **Телефон (детали)** — карта с историей (L2) и геозонами (L3); графики экранного времени по дням и топ приложений (T1, T4); блок «Поиск телефона»: Режим пропажи (A1), Звуковой сигнал (A2), Блокировка (A3), Сообщение на экран (A4), Запрос снимка (C1); галерея снимков; лимиты приложений (T3) и блокировка пакетов (T7, full); лента событий (R1).
3. **Геозоны** — добавить зону на карте (точка + радиус), привязать к телефону, настроить уведомления входа/выхода.
4. **Подключение** — «Создать код», код + **QR** (клиентская генерация, `assets/qrcode.min.js`), инструкция в 3 шага.
5. **Настройки** — интервал по умолчанию, лимиты по умолчанию, порог низкого заряда; email-уведомления (N1) и дайджест (N2); профили детей (F2); доступ родителей (F3); экспорт данных (R2); тема и язык панели.

### 5.3. Пустые состояния
Если данных нет — карточка: «Данные с телефона ещё не пришли. Проверьте: защита запущена, выдано "Разрешить всегда" для геолокации, отключена экономия батареи. Первый отчёт — в течение минуты.»

### 5.4. Карта
Leaflet + OpenStreetMap (без платных ключей). Маркеры с именем телефона и временем позиции; геозоны — круги; история — линия маршрута.

## 6. Безопасность и приватность
- HTTPS; токен в заголовке, не в URL.
- Снимки — в закрытой папке (`wp-content/uploads/family-guard-private/`), прямой доступ закрыт (Apache `.htaccess`; для nginx — инструкция), отдаются только администратору по nonce.
- PIN хранится как SHA-256.
- Персональные данные не кладутся в URL.
- Постоянное уведомление о работе защиты на телефоне.
- Снимок — только после явного согласия (C1) либо открыто как антивор после неудачных попыток PIN (A5).
- Экспорт и удаление данных ребёнка по требованию (R2).

## 7. Совместимость и сборка
- Android minSdk 26, targetSdk 35. Две сборки: **lite** (без службы спец. возможностей, ставится несмотря на Play Protect) и **full** (лимиты/блокировка приложений).
- Release-подпись из папки `signing` (не коммитить, бэкапить).
- WordPress PHP 8.0+, свежая версия WP; установка zip-ом; миграции через `dbDelta`.
- Карта Leaflet/OSM, без платных ключей.

## 8. Критерии приёмки
1. APK lite устанавливается на реальном телефоне без блокировки Google.
2. Привязка по QR из панели работает с первого раза.
3. После «Запустить защиту» в течение минуты телефон появляется на карте с координатами, зарядом и экранным временем.
4. Экранное время показывает время **по каждому приложению** (виден YouTube и его часы); лимит на приложение и уведомление о превышении срабатывают.
5. Геозона: вход/выход даёт уведомление родителю (в панели и на email).
6. SOS с телефона ребёнка доставляет родителю сигнал с геолокацией.
7. Меню WordPress — одна иконка; по клику — страница со всеми вкладками.
8. Интерфейс APK и панели соответствует дизайн-системе (раздел 3), светлая и тёмная темы.
9. Режим пропажи, звуковой сигнал, блокировка, сообщение на экран срабатывают по команде из панели.
10. Снимок (C1) делается только после нажатия ребёнком; A5 — только после неудачных попыток PIN и при открытом предупреждении на устройстве.
11. Нет скрытой съёмки, прослушки, чтения переписки и маскировки иконки.

## 9. Этапы работы
- **Этап 1 — Плагин.** Меню-иконка + страница с вкладками, карта Leaflet, Обзор, Детали телефона, Подключение с QR. Чтобы данные наконец отображались красиво.
- **Этап 2 — APK, интерфейс.** Splash, онбординг, привязка, разрешения, Главный, Экранное время по приложениям, Настройки — по дизайн-системе.
- **Этап 3 — Функции.** Геозоны, SOS, история, лимиты приложений, уведомления (email), режим пропажи/сигнал/блокировка/сообщение, антивор A5, защита от удаления — до критериев приёмки.
- **Этап 4 — Сборка и документация.** Подпись, zip плагина, инструкции, контрольные суммы, экспорт данных.
